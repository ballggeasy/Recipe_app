Recipe App สูตรอาหาร

แอปมือถือสำหรับค้นหาและแบ่งปันสูตรอาหาร โปรเจกต์รายวิชา Mobile Application ที่มหาวิทยาลัยสงขลานครินทร์ (PSU)

ทำอะไรได้บ้าง

  • ค้นหาสูตรอาหารตามชื่อ วัตถุดิบ หมวดหมู่ หรือความยาก
  • เพิ่มสูตรของตัวเองพร้อมรูปภาพ และแก้ไขภายหลังได้
  • รีวิว ให้คะแนน และแสดงความคิดเห็นในสูตรของคนอื่น
  • เก็บสูตรโปรดไว้เป็นโฟลเดอร์
  • วางแผนมื้ออาหารรายวัน/รายสัปดาห์ พร้อมสรุปพลังงานและสารอาหาร
  • ล็อกอินด้วยอีเมล/รหัสผ่าน หรือด้วยบัญชี Google

ลิงก์

  • นโยบายความเป็นส่วนตัว (Privacy Policy)
  • ซอร์สโค้ดบน GitHub
