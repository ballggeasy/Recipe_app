นโยบายความเป็นส่วนตัว Privacy Policy

ปรับปรุงล่าสุด 8 ตุลาคม 2569 (2026-10-08)

Recipe App เป็นโปรเจกต์รายวิชาของนักศึกษามหาวิทยาลัยสงขลานครินทร์ ไม่ใช่บริการเชิงพาณิชย์ หน้านี้อธิบายว่าแอปเก็บข้อมูลอะไร ใช้ทำอะไร และส่งต่อให้ใครบ้าง

ข้อมูลที่เก็บ

  • บัญชีผู้ใช้: อีเมล ชื่อที่แสดง และรหัสผ่านซึ่งเก็บเป็นค่า hash เท่านั้น ไม่เก็บรหัสผ่านจริง
  • เมื่อล็อกอินด้วย Google: แอปขอเฉพาะ scope openid, email และ profile แล้วเก็บรหัสบัญชี Google (Google ID) อีเมล ชื่อ และลิงก์รูปโปรไฟล์ แอปไม่ได้รับรหัสผ่าน Google และไม่เข้าถึง Gmail, Drive, รายชื่อติดต่อ หรือข้อมูลอื่นในบัญชี Google
  • เนื้อหาที่คุณสร้าง: สูตรอาหาร รูปภาพที่อัปโหลด รูปโปรไฟล์ รีวิว คะแนน ความคิดเห็น สูตรโปรด โฟลเดอร์ และแผนมื้ออาหาร
  • ข้อมูลทางเทคนิค: log ของเซิร์ฟเวอร์บันทึก path ของ request สถานะ และเวลาที่ใช้ เพื่อแก้ปัญหาและดูแลระบบ IP address ใช้ชั่วคราวเพื่อจำกัดจำนวน request ป้องกันการโจมตี

ใช้ข้อมูลทำอะไร

  • ยืนยันตัวตนและทำให้คุณใช้ฟีเจอร์ของแอปได้
  • แสดงชื่อและรูปโปรไฟล์ของคุณคู่กับสูตร รีวิว และความคิดเห็นที่คุณโพสต์ ผู้ใช้คนอื่นจะเห็นข้อมูลส่วนนี้
  • ประเมินโภชนาการของสูตรอาหาร (ดูหัวข้อถัดไป)

ไม่มีการขายข้อมูล ไม่ใช้โฆษณา และไม่ใช้เครื่องมือติดตามพฤติกรรมของบุคคลที่สาม

ผู้ให้บริการที่ข้อมูลผ่าน

  • Microsoft Azure: เซิร์ฟเวอร์และฐานข้อมูลของแอปอยู่บน virtual machine ของ Azure ในภูมิภาค Malaysia West
  • Google: ใช้ยืนยันตัวตนเมื่อคุณเลือกล็อกอินด้วย Google
  • PSU dotBlue AI (ai.psu.blue): เมื่อมีการสร้างหรือแก้ไขสูตรอาหาร เซิร์ฟเวอร์จะส่งชื่อสูตร รูปของสูตร (ถ้ามี ย่อขนาดแล้ว) รายการวัตถุดิบ และจำนวนที่เสิร์ฟ ไปให้โมเดล AI ประเมินคุณค่าทางโภชนาการ ข้อมูลบัญชีของคุณไม่ได้ถูกส่งไปด้วย

การเก็บรักษาและการลบข้อมูล

  • ข้อมูลถูกเก็บไว้ตราบเท่าที่บัญชียังอยู่ หรือจนกว่าโปรเจกต์จะปิดตัว
  • ลบบัญชีได้เองที่หน้าโปรไฟล์ในแอป ระบบจะลบข้อมูลบัญชี (อีเมล ชื่อ รหัสผ่าน และรหัสบัญชี Google) ออก
  • สูตร รีวิว และความคิดเห็นที่โพสต์ไปแล้วจะยังแสดงอยู่พร้อมชื่อที่ใช้ตอนโพสต์ ถ้าต้องการให้ลบ ให้ลบเนื้อหาเหล่านั้นก่อนลบบัญชี
  • สูตรโปรด โฟลเดอร์ แผนมื้ออาหาร และไฟล์รูปโปรไฟล์ที่อัปโหลด อาจยังค้างอยู่บนเซิร์ฟเวอร์หลังลบบัญชี แต่จะไม่ผูกกับอีเมลหรือชื่อของคุณแล้ว ถ้าต้องการให้ลบทั้งหมด แจ้งทีมพัฒนาผ่านช่องทางด้านล่าง
  • ถอนสิทธิ์ที่ให้แอปเข้าถึงบัญชี Google ได้ที่ myaccount.google.com/connections

ความปลอดภัย

การเชื่อมต่อระหว่างแอปกับเซิร์ฟเวอร์เข้ารหัสด้วย HTTPS รหัสผ่านเก็บเป็น hash และ session ใช้ token ที่มีวันหมดอายุ อย่างไรก็ตาม นี่เป็นโปรเจกต์ของนักศึกษา จึงไม่ควรใช้รหัสผ่านเดียวกับบริการสำคัญอื่น
